# Приглашение на свидание 💌

Готовый статический сайт без сборки и без зависимостей.

## Что умеет

- вопрос «Пойдёшь со мной на свидание?»;
- кнопка «Нет» убегает от курсора и не нажимается;
- на телефоне «Нет» также убегает от касания;
- после «Да» появляется красивый календарь;
- выбор даты и времени;
- кнопка «Отправить мой ответ» открывает системное меню «Поделиться»;
- если Web Share API недоступен — ответ копируется в буфер;
- адаптивная мобильная версия.

## Как запустить у себя

Просто открой `index.html` двойным кликом.

Для корректной проверки кнопки «Поделиться» лучше открыть сайт через HTTPS после публикации.

## Как изменить текст

Открой `script.js` и измени:

```js
const CONFIG = {
  question: "Пойдёшь со мной на свидание?",
  shareIntro: "Да 💗 Я согласна на свидание!",
};
```

Главный заголовок сейчас прописан также в `index.html`, чтобы он сразу отображался без JavaScript.

## Самый простой бесплатный деплой — Netlify Drop

1. Распакуй ZIP.
2. Открой https://app.netlify.com/drop
3. Перетащи в окно папку `date-invite`.
4. Получишь ссылку вида `something.netlify.app`.
5. Эту ссылку отправляешь девушке.

Альтернативы: Cloudflare Pages Direct Upload или GitHub Pages.

## Важно

Сайт полностью статический и ничего не сохраняет на сервер.
После выбора даты девушка нажимает «Отправить мой ответ 💌» и выбирает Telegram / WhatsApp / другой мессенджер.

Если позже захочешь, можно подключить Telegram-бота или серверную форму, чтобы выбранная дата прилетала тебе автоматически.
